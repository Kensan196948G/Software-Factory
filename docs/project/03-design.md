## 3. 画面状態

Normal / Empty / Loading / Validation Error / Communication Error / Success を全画面で定義（設計成果物 §12）。トーストは7秒・「元に戻す」は取り消し可能な遷移のみ。エラーはコード（ERR-xxx）と問い合わせIDを表示し、入力は消さない。

## 4. レスポンシブ・アクセシビリティ

- PC中心（1280×800以上）。1200pxで左ナビ212px、900pxでアイコン化、720px未満で下部タブ＋カード表示。
- キーボード完結、Escで閉じる、フォーカストラップ、可視フォーカス、`aria-live`、`role="alert"`。
- 信号は色＋文字ラベル、滞留は左線＋「n日目」ラベル。コントラスト4.5:1以上、`prefers-reduced-motion` 対応。

## 6. 既存仕様との差異（意識的に採用した点）

| 項目     | 仕様                                   | MVPの採用                | 理由                                                    |
