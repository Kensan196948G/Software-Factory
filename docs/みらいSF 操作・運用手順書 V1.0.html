0文書管理・この文書の読み方

第1部 はじめに ― この手順書が何のためのもので、だれがどこを読めばよいかを示します。

1受付ステーションのしくみ

操作を始める前に、画面の地図と、依頼が流れていくしくみを1枚ずつ見ておきます。

1-1. 画面の地図

受付ステーションは、左（スマートフォンでは下）のメニューで5つの画面を切りかえます。依頼を押すと右から「詳細」が出てきて、状態を変えるときは「状態を変更」の小窓が開きます。

1-2. 信号の3色

どの依頼にも信号の色を付けます。入力に合わせて画面が色の候補を自動で出しますが、最後に色を決めるのは承認者です。迷ったら1つ上の色にします。

青どんどん任せる

記録・整理・検索・お知らせ。まちがえてもすぐ直せて、人やお金に直接ひびかないもの。例：工事写真の整理、作業日報、入札・発注情報のお知らせ

黄担当者のチェック付き

たたき台づくり・比べっこ・見落としチェック。結果は必ず担当者や技術者が見てから使う。例：KY記録の書きもれ確認、天気・波・潮の予報の目安

赤AIに決めさせない

合否・金額・契約・人の処遇・安全（出航・作業中止など）を決める仕事。道具は「材料集め・表示」まで。例：見積金額の決定、船を出すかの判断

海の工事では、天気・波・潮の予報を集めて見せるのはAIの得意なこと（黄）です。でも「今日は船を出すか」「作業を止めるか」は、船長や現場の責任者が決めます（赤）。画面にも「作業できる／できない」とは表示しません。

1-3. 依頼の状態の流れ

依頼は「受付」から「完了」まで、次の順に進みます。書き直しが必要なときは「差戻し」、今回は作らないときは「見送り」になります。

1-4. 「あなたの番」と滞留日数の印

ホームの先頭には、いまあなたが動かす依頼だけが「あなたの番」として並びます。止まっている日数の長いものが上です。左メニューの「ホーム」に付く数字も、あなたの番の件数です。

2依頼者の操作

第2部 操作手順 ― 現場・部署で「困った」「これがあったら」を依頼する人の手順です（OP-01〜OP-09）。

依頼は「注文書（作業指示書）」の下書きです。AIはこの注文書を読んで道具を作り、検査機は「合格の条件」で合否を決めます。だから、どうなれば合格かを、だれが読んでも同じ意味になる言葉で書くことが、いちばん大事です。

OP-01　受付ステーションを開いて、自分になっているか確かめる

  1. 開く受付ステーション（mirai-construction-sf-intake.html）を Edge または Chrome で開きます。
  2. 自分を確かめる試作 上の帯の「操作する人」で、自分の役割（依頼者）を選びます。本番 会社のアカウント（Entra ID）で自動的に識別されるので、操作は不要です。
  3. ホームを見る先頭の「あなたの番」に、あなたが動かす依頼が出ます。「いま、あなたが動かす依頼はありません。」なら、待っていて大丈夫です。

OP-02　新しい依頼を出す（7つのSTEP）

ホームの「新しい依頼をはじめる」、または左メニューの「新しい依頼」を押します。上に STEP 1〜7 の帯が出ます。「つぎへ」で進み、「もどる」で戻ります（戻っても入力は消えません）。必須の印がある項目を空のまま「つぎへ」を押すと、赤い枠で足りない項目が示されます。

STEP画面の見出し入れること（太字は必須）コツ
1 はじめにどんな依頼ですか？依頼の種類（新しい道具がほしい／いまある道具を良くしたい／不具合の報告／相談・アイデア）、道具カタログから選ぶ（任意）近い道具がカタログにあれば選ぶ（OP-03）。なくても大丈夫

  1. 右側を見ながら入れる画面の右（スマートフォンでは下）に「信号の色（判定の候補）」「ものさし（参考値）」「注文書プレビュー」が出ます。入力のたびに変わるので、色の理由を見ながら進めます。
  2. 受け付けるSTEP 7 で「この内容で受け付ける」を押すと、受付番号と日付の入った「受付」のハンコが出て、ボードへ移ります。下書きはこのとき消えます。
  3. 番号を控える受付番号（例：REQ-2026-0010）が、問い合わせのときの目印になります。
「扱う情報」を1つでも選ぶ、「関わる相手」を社内のみ以外にする、「必ず人に聞くこと」で安全・品質や作業船の運航を選ぶと、信号の候補は少なくとも黄になります。これは「チェックを付けて慎重に進める」という意味で、悪いことではありません。

OP-03　道具カタログから近い道具を選ぶ

  1. 部署を押すSTEP 1 の「部署別 道具カタログから選ぶ（任意）」で、部署のボタンを押します。その部署の道具の候補が出ます。丸の色はカタログ上の信号の色です。
  2. 道具を押す近い道具を押すと「（道具名）」を選びました（件名・部署・信号の候補に反映）と出て、件名（空のときだけ）・部署・「この道具がすること」の初期値が入ります。
  3. やめるとき「選択を外す」を押すと、カタログ外の依頼になります。カタログにない依頼もそのまま出せます。

カタログには19部署・118件の道具の候補があります（青52・黄47・赤19）。★は「はじめやすい候補」で、着手の順番ではありません。全件は詳細仕様書の付録にあります。

OP-05　書きかけの依頼を「続きから再開」する／破棄する

入力の途中で画面を閉じても、入力はこのブラウザに自動で下書き保存されています。入力画面の下に「下書きを自動保存しました　（時刻）」と出ていれば保存済みです。

下書きはこのブラウザに1つだけです。別のPCやスマートフォン、別のブラウザでは見えません。ブラウザのサイトデータを消すと下書きも消えます。本番では、下書きは利用者ごとにサーバ側に保存し、本人だけが見られるようにします（保存期間は Q-14）。

OP-06　自分の依頼の進み具合を見る

  1. ホームで見るホームの「あなたの依頼（ほかの人の番）」に、ほかの人が動かす番の自分の依頼が、状態・滞留日数・「次は（だれ）」付きで出ます。
  2. 詳細で見る依頼を押すと詳細が開きます。先頭に「次に動かすのは（受付担当／承認者）です（いまの状態になってから n 日）」が出ます。「コメント・履歴」タブで、だれが・いつ・何をしたかを確かめられます。
  3. 質問する「コメント・履歴」タブの入力欄に書いて「コメントする」を押すと、記録に残ります。

OP-07　差戻しを直して再提出する

差戻しになった依頼は、あなたの番になります。理由はコメントと変更履歴に残っています。

  1. 開くホームの「あなたの番」で、差戻しの依頼の「直す」を押します（詳細の「指摘を直す（直したら再提出）」でも同じです）。
  2. 直す入力画面が開くので、理由に書かれた所を直します。上の帯で、直したいSTEPへ直接移れます。
  3. 再提出するSTEP 7 の「直した内容で再提出する」を押します。依頼は「受付」に戻り、履歴に「再提出（指摘に合わせて内容を直しました）」と残ります。
直す必要がなく、そのまま受付に戻したいときは、ボードのカードの「受付へ」ボタンでも再提出できます。ただし理由に応えた直しをしてから戻すのが基本です。

OP-08　現場試用の感想をコメントする

  1. 開くホームの「あなたの番」で、現場試用の依頼の「感想を書く」を押します。詳細の「コメント・履歴」タブが開きます。
  2. 書く屋外・手袋・雨の日・電波の弱い所で使ってみてどうだったか、困った所を具体的に書きます（例：「台船の上で手袋のまま押せた。圏外でも写真が残った」）。
  3. 送る「コメントする」を押します。完了にするかどうかは承認者が判断します。

OP-09　依頼を取り下げる（見送り）

もう必要なくなった依頼は、「受付」または「差戻し」のときだけ、自分で取り下げられます。

  1. 小窓を開く詳細の「状態を変更」を押します。「受付」のときは、選べる状態として「見送り」だけが出ます（「差戻し」のときは、再提出の「受付」も出ます）。
  2. 理由を書く「見送り」を選ぶと、メモが（必須）になります。「依頼者から取り下げの申し出がありました。」などの理由の候補を押すと、メモに入ります。
  3. 確定「変更する」を押します。
依頼者が動かせるのは、自分が起票した依頼の「差戻し→受付（再提出）」と「受付・差戻し→見送り（取り下げ）」だけです。ほかの人の依頼や、ほかの状態は、小窓に「いまの役割（依頼者）では、この依頼の状態は変えられません。」と出て、選べない理由が一覧で見られます。依頼者は依頼を削除できません。

OP-10　「あなたの番」から一日を始める

OP-11　受け付けた依頼の中身を確かめる

  1. 概要を読む詳細の「概要」タブで、困りごと・目的・使う人と場所・作るもの・今回は作らない・合格の条件・扱う情報を読みます。合格の条件で「△ 書き直しをおすすめ」が付いた行は、ヒントと例が添えてあります。

OP-12　注文書を整えて、承認を依頼する

  1. 編集で整える詳細の「編集」で、依頼者と相談しながら合格の条件・今回は作らない・扱う情報・必ず人に聞くことを整えます。最後は「この内容で更新する」。履歴に「内容を編集」が残ります。
  2. 注文書を確かめる「注文書」タブで YAML を読み、目的・対象・対象外・合格の条件・守ること・必ず人に聞くことがそろっているか確かめます（OP-16）。
  3. 承認待ちへ「「承認待ち」へ進める」を押します。承認者の「あなたの番」に出ます。
承認を依頼する前に、受付担当が17章の「承認前チェックリスト」で同じ点を見ておくと、差戻しが減ります。

OP-13　カードの「次へ」で進める ― 元に戻す

  1. 押すボードの各カードの下にある「→（次の状態）へ」ボタンを押します。押してもカードの詳細は開きません。

  4. 小窓が開く状態承認済み・完了へは、確認の小窓（承認前チェックなど）が開きます。これは承認者の操作です。

4承認者の操作

業務責任者・現場所長として、何を作るかと信号の色を決め、承認・差戻し・見送り・完了を判断する人の手順です（OP-20〜OP-26）。

承認は「この注文書のとおりに作ってよい」というハンコです。AIの「できました」でも検査機の「合格」でもなく、最後に決めるのは人です。だから画面は、ハンコを押す前に見落としがないかを自動で並べて見せます。

OP-20　承認待ちの依頼を開く

  1. ホームを開く「あなたの番」に、自分が承認者になっている承認待ち・現場試用の依頼が、止まっている日数の長い順に出ます。
  2. 中身を読む行を押して詳細の「概要」を読みます。先頭に「あなたの番です：信号の色を決めて、承認か差戻しを決める」と出ます。
  3. 承認の小窓へ行の「「承認済み」へ」ボタン、または詳細の「「承認済み」へ進める」を押すと、承認の小窓が開きます。

  2. ゆるい色にするとき候補より低い色（例：候補が黄で青にする）を選ぶと、「候補（黄）より ゆるい色 にします。理由をメモに書いてください。」と出ます。メモに理由を書かないと「候補よりゆるい色にする理由をメモに書いてください」と出て、承認できません。
  3. 確定「変更する」を押します。履歴に「信号の色を「（色）」に決定（候補は「（色）」）／承認前チェック △n件を確認」が残ります。

OP-23　赤信号を確認する

  1. 範囲を確かめる赤の依頼は、そのままでは作りません。道具の範囲が「材料集め・表示」までに変わっているかを確かめます。変わっていなければ差戻しにします。
  2. 確認の印赤を選ぶと「赤信号の仕事は AIに決めさせません。道具の範囲が「材料集め・表示」までで、決定は人が行うことを確認しました。」が出ます。印がないと「赤信号の確認にチェックしてください」と出て、承認できません。
  3. 技術者に聞く安全・構造・品質・法令にかかわるものは、資格と責任を持つ技術者に確認してから決めます。
見本の REQ-2026-0007「見積金額を自動で決めたい」は赤の候補のため、「金額の決定は赤信号（AIに決めさせない）です。「過去工事との見積比べ（黄）」や「社内単価・作業船の費用データの検索（青）」に範囲を変え、合格の条件を数字で書き直して再提出してください。」と差し戻されています。

  1. 依頼にするCI定義・保護ルール・権限・注文書のひな形・信号ルール・カタログの変更を、依頼として受付に登録する。
  2. 影響を確かめる変更で弱くなる検査や、広がる権限がないかを確かめ、PRに書く。
  3. 承認する工場の管理責任者が承認する。合格の条件を削る・弱める内容を含むときは内部監査にも知らせる 提案。
  4. 反映して残すPR経由で反映し、変更履歴を残す。カタログの変更は依頼画面に反映し、関係者へ知らせる。
実装AIは、CIの定義・保護ルール・セキュリティ検査を変えられません。変えようとするPRは承認待ちで止まります。これは「検査を弱めて合格にする」ことを防ぐためです。

道具を作るときも、使うときも、働く人の権利と公正を守ります。運用で守ることを具体的にします。 S4

働く人の情報を守る

だれも取り残さない

声を上げた人を守る

ヒヤリハットや内部通報をした人が不利にならないようにし、通報者の情報は担当者以外に見せません。障害の振り返り（OP-35）も、個人を責めず仕組みを直すために行います。

書きかけの依頼が見当たらない別のPC・別のブラウザで開いている／サイトデータを消した／「下書きを破棄」した／受け付けたので消えた下書きはブラウザに1つだけです（OP-05）。受け付け済みなら一覧で件名を検索する。本番では利用者ごとにサーバに保存されます
「新しい依頼」を押しても新しく始まらない入力中の依頼を表示している（「入力中の依頼を表示しています（新しく始めるときは「下書きを破棄」）」）、または書きかけがあるいまの下書きを「下書きを破棄」してから始める。または小窓で「破棄して新しく始める」
依頼の編集を始めようとしたら「書きかけの依頼があります」と出た別の依頼の書きかけがある（下書きは1つだけ）書きかけを残したいなら先に受け付けるか、「キャンセル」。破棄してよければ「破棄して編集する」
「編集していた依頼が見つかりません（削除された可能性があります）」と出た編集の途中で、その依頼が削除された受付担当に確認する。本番では削除はなく「取消」になります
ボタンが押せない・選べない
カードに「→」ボタンがなく「次は（受付担当）」などと出るその依頼は、いまあなたの番ではない（役割が違う、または自分の依頼ではない）表示された人が動かすのを待つ。急ぐならコメントで知らせる
状態変更の小窓に「いまの役割（依頼者）では、この依頼の状態は変えられません。」と出る依頼者は、自分の依頼の「差戻し→受付」「受付・差戻し→見送り」しかできない「選べない状態とその理由」を開いて、だれができるかを見る（OP-14）
「「承認済み」にできるのは承認者だけです（最後は人が決めます）」と出る承認・完了は承認者の仕事承認者に頼む。受付担当は「承認待ち」へ進めるところまで
「ほかの人の依頼は動かせません（起票者：…）」と出る依頼者は自分が起票した依頼だけ動かせる起票した人か受付担当に頼む
「編集」が押せない（「いまの役割・状態では編集できません」）依頼者は自分の依頼の「受付」「差戻し」のときだけ編集できる。完了した依頼はだれも編集できない直したいことはコメントで受付担当へ。完了後の改善は新しい依頼（「いまある道具を良くしたい」）で出す
「削除」が押せない（「依頼者は削除できません」）依頼者は削除できない不要になったら取り下げ（OP-09）
承認しようとすると「承認前チェックの △ を確認して、チェックを入れてください」と出る承認前チェックに△があり、確認の印がない△を読み、問題なければ印を付ける。直してほしければ差戻し（OP-21）
「候補よりゆるい色にする理由をメモに書いてください」と出る候補より低い色を選んだメモに理由を書く（OP-22）
「赤信号の確認にチェックしてください」と出る赤で承認しようとして確認の印がない範囲が「材料集め・表示」までになっているか確かめて印を付ける（OP-23）
「理由をメモに書いてください（候補を押すと入ります）」と出る差戻し・見送りの理由が空理由の候補を押すか、自分で書く（OP-15、OP-24）
あなたの番・滞留
自分の依頼が「あなたの番」に出ない依頼者の番になるのは「差戻し」と「現場試用」のときだけ。ほかの状態は別の人の番ホームの「あなたの依頼（ほかの人の番）」で進み具合を見る（OP-06）
承認者なのに承認待ちが「あなたの番」に出ないその依頼の承認者が自分ではない詳細の「承認者」を確かめる。付けかえは受付担当へ（OP-41）
滞留日数が思ったより多い日数は「受付」または最後の状態変更からの日数。編集やコメントでは数え直さないそのままで正しい表示です。止まっている理由をコメントに残す
書き出し・取り込み
「このファイルは取り込めません」と出る受付データの形式ではない（items の一覧がない、受付番号や件名が文字でない など）「JSONで書き出す」で作ったファイルを使う。データは変わっていません
JSON を取り込んだら、前のデータがなくなった取り込みは全件の置きかえ取り込む前に「JSONで書き出す」で保存しておく（OP-18）
CSV を Excel で開くと文字化けする古い開き方をしているダブルクリックで開く（文字化けしない形式で書き出しています）。だめならデータの取り込み機能で UTF-8 を選ぶ
「書き出せませんでした」「コピーできませんでした」と出るブラウザがダウンロードやクリップボードを止めているブラウザの設定でダウンロードを許可する。コピーは YAML を選んで手でコピーする
入力
「つぎへ」を押すと赤い枠でメッセージが出て進めない必須の項目が空（例：「使う人を1つ以上選んでください」「合格の条件を1つ以上書いてください」）メッセージの項目を入れる
合格の条件に「など」を書いたら△になった「など」はあいまい語の一覧に入っている対象を書き出す（例：「写真と動画を保存できる」）。誤検知の扱いは Q-16 で見直し中
添付したファイルが詳細で開けない試作ではファイル名と大きさだけを記録している本物の資料は送らない。本番では文書管理に保存されリンクで開ける（Q-17）
