3. **G1・G3 の TC 改訂**（UI で期待値を実測に合わせる。実装を直す場合は不要）。
4. **G5 の実測**（15 分窓）を行い、TC-RATE-01 を executed にする。
5. すべて反映後、レポートを再版する（版番号は工作台を正とする）。
