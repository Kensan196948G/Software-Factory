## 判定の凡例

| 判定 | 意味                                                         |
| ---- | ------------------------------------------------------------ |
| 済   | 要件の主要部分がコードにあり、自動試験がある                 |
| 一部 | 一部のコードはあるが、要件を満たさない部分が残る             |
| 未   | 該当するコードがない（関連データや文書だけの場合を含む）     |
| 手動 | 自動試験がなく、人手の実測記録だけがある（判定列に併記する） |
